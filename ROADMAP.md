# Roadmap

Дорожная карта Dajet Player. Что планируется, что не в планах — никогда.

Очередь волн и решения владельца живут в эпике JOER: [`bestdeejay-design/joer#7`](https://github.com/bestdeejay-design/joer/issues/7).

---

## Текущее состояние

**0.1.0 — он живёт в трее, окно знает своё состояние, а вибрацию выбирает трей (P-02…P-06R, P-10, P-10R).** Проект собирается, приложение открывается, папку или файлы можно бросить в окно — играют один за другим; плеер знает, что играет: название, исполнитель и альбом из файла, обложка — из встроенных тегов или из файла рядом, Next/Previous, shuffle и repeat на месте. Медиа-клавиши клавиатуры, карточка Now Playing, тонкая полоса прогресса с перемоткой, громкость и mute (persist) — тоже его; `←`/`→` ходят по очереди рядом со Space. Окно — стекло по всей поверхности в светлой теме (прозрачнее прежнего) и матовый почти-чёрный в тёмной; слева — системная колонка split-view с плейлистами-папками (⌘O или drag&drop; свой `Codable`-файл, живут до удаления); вверху — системный тулбар: тумблер меню слева, Open Folder и тема справа. Плеер теперь и в трее: собственная иконка, полное меню (текущий трек, транспорт, плейлисты с ленивыми подменю, Open Folder, тема, настройки, показать/выйти), анимация иконки во время игры. Обложки читаются из встроенных тегов и из файлов рядом (`folder.jpg`, `cover.jpg` и т.п.), с кэшем. Окно знает два шаблона — Horizontal 548×284 и Vertical 232×441 — и Custom без snap-back; в трее три пресета Appearance — Aero / Obsidian / System; тот же пресет сохраняет шаблон, другой — возвращает дефолт. Клик по иконке трея прячет окно и показывает его снова; в меню Shuffle / Repeat / Volume и тихая строка прогресса. Ядро P-03…P-05 не тронуто; `Presentation.swift` и 16 регрессионных тестов — на месте.

Нумерация релизов сверялась перед P-03 и осталась прежней; текущий тег проекта в `VERSION` — `0.1.0`.

**Что есть сейчас:**
- `Package.swift` — один executable-таргет `DajetPlayer`, macOS 14+, swift-tools 6.0, language mode 5, ноль зависимостей
- `Sources/DajetPlayer/App.swift` — одно окно; версия «dajet»: окно-плеер (обложка, название, транспорт) и боковое меню плейлистов; системный тулбар (тумблер колонки ⌥⌘S, Open Folder ⌘O, тема); drop папок и файлов, Space, `←`/`→`; тонкая полоса прогресса с перемоткой по отпусканию, слайдер громкости и кнопка mute; клампы: формальный квадрат от 232 pt контента (окно 232×284 = +52 тулбар), при открытии колонки на узком окне окно расширяется, чтобы колонка и плеер стояли рядом в системном split-view
- `Sources/DajetPlayer/Presentation.swift` — шаблоны окна (H 548×284, V 232×441, Custom без snap), пресеты Appearance (Aero / Obsidian / System), общее состояние колонки и миграция (существующий альбом не трогаем, чистый запуск — Aero + Vertical + колонка закрыта)
- `Sources/DajetPlayer/Tray.swift` — трей (`NSStatusItem`): template-иконка кодом, `menuNeedsUpdate`, ленивые подменю плейлистов, анимация 4 fps (8 шагов, 0.45…0.70) только во время игры; Show прячет/показывает окно; Window templates / Appearance presets / Side Menu toggle / Shuffle / Repeat / Volume / тихая строка прогресса; клик по треку — показать окно; трей владеет движком/плейлистами
- `Sources/DajetPlayer/Artwork.swift` — обложки: AVFoundation (embedded) → байты файла ID3v2/FLAC → sidecar (`folder.jpg`, `cover.jpg` и т.п. рядом с треком), кэш по mtime, `ArtCache`, `keep()`
- `Sources/DajetPlayer/Design.swift` — палитра парами light/dark (терракота серии), метрики, анимации (`Motion.settle`/`Motion.quick`), тема (light/dark/system, ключ `look`), учёт Reduce Motion и Reduce Transparency
- `Sources/DajetPlayer/Window.swift` — поверхность окна (стекло `.underWindowBackground` в светлой теме — прозрачнее прежнего, матовый почти-чёрный в тёмной), прозрачный титлбар
- `Sources/DajetPlayer/Side.swift` — боковое меню: колонка системного split-view (176…240 pt в шаблонах, до 440 pt в Custom; системный разделитель и анимация), плейлисты с треками, отметка играющей папки и трека; без собственного тулбара и кнопки в подвале (P-10)
- `Sources/DajetPlayer/Playlists.swift` — плейлисты-папки: `Codable`-файл `~/Library/Application Support/Dajet Player/playlists.json` (запись вне главного потока, атомарно), добавление панелью или drop, удаление только рукой
- `Sources/DajetPlayer/PlayerEngine.swift` — очередь файлов + один `AVPlayer`: авто-переход по концу трека, пропуск битых файлов, mp3/m4a/flac/wav/aiff; метаданные (title/artist/album/artwork) читаются асинхронно из файла, имена кэшируются; Next/Previous с правилом 3 секунд; Fisher–Yates shuffle индексов без повторов в проходе; repeat off→all→one; медиа-клавиши через `MPRemoteCommandCenter`, карточка Now Playing через `MPNowPlayingInfoCenter`, `position`/`duration`/`seek(to:)`, громкость и mute в `UserDefaults`
- `.github/workflows/build.yml` — CI: runner macOS 15, версии Swift/Xcode не закреплены (публикуются в notice), debug+release+`build.sh`; ошибки компилятора — аннотациями к PR, размер бандла — notice
- `build.sh` — собирает `build/DajetPlayer.app` (`ru.dajet.player`, ad-hoc подпись, dSYM рядом)
- Структура и скрипты — зеркало [`dajet-browser`](https://github.com/bestdeejay-design/dajet-browser)

**Чего нет (честно, с блокерами):**
- Desktop-виджет (блокеры: второй продукт в `Package.swift`, `.appex` в `build.sh` — оба заморожены)
- `LSUIElement` в plist (runtime-политика + тумблер Dock по умолчанию выключен)
- Гарантированного `Assets.car` с Dark/Tinted-стилями Dock на сборках без Xcode 26: `.icns` генерируется всегда, `Assets.car` — только если доступен `actool` Xcode 26
- Версия `joer`: пять атмосфер
- Опубликованного релиза и нотаризации: `build.sh release dmg` уже создаёт dmg/zip/appcast, `release.sh` и `tap.sh` написаны, но публикация не запускалась; пока подпись ad-hoc

## Принципы (не обсуждаются)

- **zero-dep** — только системные фреймворки Apple, включая SwiftUI, AppKit, AVFoundation и MediaPlayer. Ни одной сторонней зависимости.
- **Ноль сетевых запросов в рантайме** — проверяемо: Network Monitor пуст.
- **Тишина** — без аккаунтов, облака, телеметрии и «онлайн-виджетов».
- **Перф-бюджет** — idle CPU < 5% на M1; бандл < 15 МБ (до ~25 МБ с Metal-шейдерами); без просадок при ресайзе окна.

## Две версии оформления

Ядро воспроизведения — общее и лёгкое; оформление — сменный слой, отключаемый.

| Версия | Оформление |
|---|---|
| **dajet** | тёмная + светлая тема, глассморфизм (Liquid Glass / `NSVisualEffectView`) |
| **joer** | атмосферы как на сайте: `lounge` · `club` · `romantic` · `space` · `velvet` |

Палитра серии: тёмная подложка `#15181C`, терракотовый акцент `#E8AE8C`, текст `#F4F1E8`.

В версии `dajet` тёмное окно глубже подложки: `#15181C` — это фон *страницы* внутри окна, и целое окно из него читается серым. Светлое окно — стекло по всей поверхности; акцент остаётся терракотовым в обеих темах.

## Что не в планах

- Ни одного сетевого запроса: ни обложек из интернета, ни телеметрии, ни аккаунтов, ни облачной библиотеки
- Ни одной сторонней зависимости — ни через SwiftPM, ни вкомпилированной
- Ни Xcode-проекта: только `Package.swift`

# Roadmap

Дорожная карта Dajet Player. Что планируется, что не в планах — никогда.

Очередь волн и решения владельца живут в эпике JOER: [`bestdeejay-design/joer#7`](https://github.com/bestdeejay-design/joer/issues/7).

---

## Текущее состояние

**v0.3.0 — системные клавиши принадлежат ему (P-02, P-03, P-04, P-05).** Проект собирается, приложение открывается, папку или файлы можно бросить в окно — играют один за другим; плеер знает, что играет: название, исполнитель и альбом из файла, обложка размыта за окном, Next/Previous, shuffle и repeat на месте. Медиа-клавиши клавиатуры, карточка Now Playing в Control Center, тонкая полоса прогресса с перемоткой, громкость и mute (persist) — тоже его; `←`/`→` ходят по очереди рядом со Space.

**Плюс версия «dajet» (P-06R), ещё без номера.** Окно — стекло по всей поверхности в светлой теме и матовый почти-чёрный в тёмной; слева выезжает на пружине боковое меню с плейлистами-папками (⌘O или drag&drop; свой `Codable`-файл, живут до удаления); в главном окне — плеер, а не список: обложка, название, транспорт. Ядро P-03…P-05 не тронуто, старт пустой. Приёмка и номер версии — за владельцем (`joer#17`).

Нумерация релизов сверялась перед P-03 и осталась прежней; текущий тег проекта в `VERSION` — `0.1.0`.

**Что есть сейчас:**
- `Package.swift` — один executable-таргет `DajetPlayer`, macOS 14+, swift-tools 6.0, language mode 5, ноль зависимостей
- `Sources/DajetPlayer/App.swift` — одно окно без тулбара; версия «dajet»: окно-плеер (обложка, название, транспорт) и боковое меню плейлистов; drop папок и файлов, «Open Folder…» (⌘O), Space, `←`/`→`; обложка из файла — размытие вне главного потока, плавный фейд за окном; тонкая полоса прогресса с перемоткой по отпусканию, слайдер громкости и кнопка mute
- `Sources/DajetPlayer/Design.swift` — палитра парами light/dark (терракота серии), метрики, пружины (`Motion.glide`/`settle`/`quick`), тема (light/dark/system), учёт Reduce Motion и Reduce Transparency
- `Sources/DajetPlayer/Window.swift` — поверхность окна (стекло `behindWindow` в светлой теме, матовый почти-чёрный в тёмной), прозрачный титлбар и `DragStrip` вдоль верхней полосы
- `Sources/DajetPlayer/Side.swift` — боковое меню: механика колонки браузера (232 pt, перетаскивается за край 176…440, выезжает на `Motion.glide`), видимый тумблер в левом верхнем углу, плейлисты с треками, отметка играющей папки и трека
- `Sources/DajetPlayer/Playlists.swift` — плейлисты-папки: `Codable`-файл `~/Library/Application Support/Dajet Player/playlists.json` (запись вне главного потока, атомарно), добавление панелью или drop, удаление только рукой
- `Sources/DajetPlayer/PlayerEngine.swift` — очередь файлов + один `AVPlayer`: авто-переход по концу трека, пропуск битых файлов, mp3/m4a/flac/wav/aiff; метаданные (title/artist/album/artwork) читаются асинхронно из файла, имена кэшируются; Next/Previous с правилом 3 секунд; Fisher–Yates shuffle индексов без повторов в проходе; repeat off→all→one; медиа-клавиши через `MPRemoteCommandCenter` (play/pause/play-pause/next/prev — руки на кнопки окна), карточка Now Playing через `MPNowPlayingInfoCenter` (title/artist/duration/elapsed/rate/обложка, снятие при idle), `position`/`duration`/`seek(to:)` для прогресса, громкость и mute в `UserDefaults` (читаются до первого трека)
- `build.sh` — собирает `build/DajetPlayer.app` (`ru.dajet.player`, ad-hoc подпись, dSYM рядом)
- Структура и скрипты — зеркало [`dajet-browser`](https://github.com/bestdeejay-design/dajet-browser)

**Чего нет:**
- Версии `joer`: пять атмосфер
- Релиза: dmg, zip, appcast, Homebrew tap, иконка

## Принципы (не обсуждаются)

- **zero-dep** — только фреймворки Apple: SwiftUI + AVFoundation + MediaPlayer. Ни одной сторонней зависимости.
- **Ноль сетевых запросов в рантайме** — проверяемо: Network Monitor пуст.
- **Тишина** — без аккаунтов, облака, телеметрии и «онлайн-виджетов».
- **Перф-бюджет** — idle CPU < 5% на M1; бандл < 15 МБ (до ~25 МБ с Metal-шейдерами); без просадок при ресайзе окна.

## Две версии оформления

Ядро воспроизведения — общее и лёгкое; оформление — сменный слой, отключаемый.

| Версия | Оформление |
|---|---|
| **dajet** | тёмная + светлая тема, глассморфизм (Liquid Glass / `NSVisualEffectView`) |
| **joer** | атмосферы как на сайте: `lounge` · `club` · `romantic` · `space` · `velvet` |

Палитра серии: тёмная подложка `#15181C`, терракотовый акцент `#E8AE8C`, текст `#F4F1E8`.

В версии `dajet` тёмное окно глубже подложки: `#15181C` — это фон *страницы* внутри окна, и целое окно из него читается серым. Светлое окно — стекло по всей поверхности; акцент остаётся терракотовым в обеих темах.

## Что не в планах

- Ни одного сетевого запроса: ни обложек из интернета, ни телеметрии, ни аккаунтов, ни облачной библиотеки
- Ни одной сторонней зависимости — ни через SwiftPM, ни вкомпилированной
- Ни Xcode-проекта: только `Package.swift`

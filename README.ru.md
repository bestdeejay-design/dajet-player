# Dajet Player

**Молчит. Играет.** — тихий музыкальный плеер для macOS. Нативный Swift · MIT · бесплатно.

Открываешь Dajet Player. Окно. Пока это всё.

**🌐 Версии:** [English](README.md) · **Русский**

## Где мы сейчас

**v0.1.0 — скелет.** Проект собирается через SwiftPM и `./build.sh`, и собранное открывается обычным приложением Mac: одно окно, без тулбара, без сайдбара, внутри пока ничего.

Ничего не играет. Открыть файл, метаданные, обложка и медиа-клавиши — следующие волны; очередь в [ROADMAP.md](ROADMAP.md).

## Что это

Dajet Player занимает ту же позицию, что и вся серия: **плеер, который молчит**.

Запусти и открой Network Monitor — ноль соединений. В сеть не уходит ничего, и в приложении нет кода, который туда уходит: ни телеметрии, ни аккаунтов, ни облака, ни обложек, подтянутых откуда-то, ни проверки обновлений без твоего запроса. Это не обещание: проверяемое заявление, входит в релиз-чеклист.

- SwiftUI и AVFoundation, больше ничего — никаких сторонних зависимостей
- macOS 14 и новее, Apple Silicon в первую очередь
- Одно ядро воспроизведения, две версии оформления впереди: `dajet` (тёмная и светлая, глассморфизм) и `joer` (пять атмосфер [joer.ru](https://joer.ru))

## Что умеет

Пока ничего — и этот шаг говорит об этом прямо, а не делает вид. Что идёт дальше, по порядку:

- **P-03** — открыть файл и воспроизвести; одно окно, один трек, ничего больше
- **P-04** — название, исполнитель и обложка, Next/Previous, shuffle и repeat
- **P-05** — медиа-клавиши, перемотка по прогрессу, громкость, которая остаётся где её оставили
- **после** — две версии оформления, эквалайзер, dmg и Homebrew tap (P-06…P-09)

## Собрать самому

```bash
git clone https://github.com/bestdeejay-design/dajet-player
cd dajet-player
./build.sh
```

`build/DajetPlayer.app` — двойной клик, либо `open build/DajetPlayer.app`. Нужны Swift 6 (Xcode command line tools) и macOS 14 или новее.

`swift build` сам по себе даёт просто бинарь; `./build.sh` — тот, кто заворачивает его в приложение.

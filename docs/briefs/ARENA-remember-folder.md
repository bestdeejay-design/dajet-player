## Задача одной строкой

Плеер должен восстанавливать библиотеку при запуске: помнить последнюю открытую папку
и открывать её сам. Полные требования — в **issue #13**, читать целиком.

## Почему так

Сейчас папка не запоминается вовсе: в `UserDefaults` живут громкость, mute, тема,
шаблон и ширина сайдбара — и всё. Путь к музыке не сохраняется ни в каком виде.
Открыть папку, закрыть приложение, запустить снова — окно пустое. Для плеера, который
открывают каждый день, это самый частый раздражитель.

## Что сделать по шагам

1. **Хранить bookmark, а не путь.** Папку за пределами песочницы нельзя открыть по
   строке пути: доступ теряется. Нужен security-scoped bookmark
   (`bookmarkData(options: .withSecurityScope, …)`) в `UserDefaults` и
   `startAccessingSecurityScopedResource()` при восстановлении — с корректным
   `stopAccessing…` на закрытии.
2. **Восстанавливать на старте.** При запуске: есть bookmark → открыть папку и
   заполнить очередь; нет → прежнее пустое состояние, как сейчас.
3. **Честно вести себя, когда папки больше нет.** Переименовали, удалили, вынули диск —
   не молчать и не падать: убрать bookmark, показать спокойное сообщение в пустом
   состоянии («папка больше недоступна») и дать открыть другую.
4. **Сменить папку — заменить bookmark.** Открытие новой папки не должно оставлять
   старую запись.
5. **Не ломать существующее:** открытие через ⌘O, перетаскивание, плейлисты, очередь,
   `NSOSPLastRootDirectory` в open-панели.

## Вне области

* Медиа-набор и иконка (P-09, PR #17 — закрыт и принят).
* Нативное окно, сайдбар, раскладка (PR #16) — не трогать.
* Синхронизация библиотеки, теги, обложки, плейлисты на диске.
* Канон айдентики (`brand`) — не меняется.
* Уже закрытые волны P-03…P-06R, P-10, P-10R, P-09 — не переделывать.

## Definition of Done

* [ ] открыл папку → закрыл приложение → запустил: библиотека на месте, играть можно сразу
* [ ] bookmark в `UserDefaults`, доступ берётся через `startAccessingSecurityScopedResource`
      и отпускается на закрытии
* [ ] удалённая/недоступная папка: запись убрана, в окне внятное сообщение, приложение
      не падает
* [ ] `swift test` зелёный (на момент постановки: **11 tests, 0 failures**); если
      добавил тесты на восстановление — ещё лучше
* [ ] CI (`.github/workflows/build.yml`) зелёный

## Форма сдачи (обязательно по §9 канона)

* **закоммить всю работу и запушь свою ветку**: `git push -u origin arena/<session-id>-remember-folder`.
  Работа, оставшаяся только в сессии, не сдана — её просто нет.
* **открой PR в `main`** с отчётом **в описании** (что сделано / что нет / развилки /
  риски) и строкой **`Closes #13`**. Без пуша и PR задача не считается сданной.
* прав комментировать issues у тебя нет — отчёт идёт через описание PR и владельца.
* CI зелёный; локальные коммиты не считаются.

## Правила

* вопросы — до кода, через владельца мне;
* не мержить, не пушить в `main`, не трогать чужие ветки;
* тесты зелёные до и после; существующие контракты не ломать;
* zero-dep: только фреймворки Apple, ни одной сторонней зависимости;
* ноль сетевых запросов в рантайме — обещание продукта, часть релизного чек-листа.

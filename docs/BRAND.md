# Dajet Brand Book

**Семейство приложений студии [dajet.ru](https://dajet.ru).**

Единая идентика для Dajet Player, Dajet Browser, Kiwi Cat и Watermelon Cat.
Минимализм и тишина — не эстетика «для красоты», а принцип: ничто не должно
отвлекать от сути.

---

## 1. Философия

> **Тишина как функция.**

Каждое приложение серии отвечает за одно:
- **Player** — играет музыку
- **Browser** — открывает страницы
- **Kiwi Cat** — развлекает
- **Watermelon Cat** — развлекает

Ничего лишнего: ни сети, ни телеметрии, ни «онлайн-виджетов», ни аккаунтов.
Проверяемо: Network Monitor пуст.

## 2. Цветовая система

### Основа (тёмная тема)
| Роль | HEX | Где |
|---|---|---|
| **Ground** | `#15181C` | Фон страницы/окна, глубина |
| **Surface** | `#1E2227` | Карточки, elevated surface |
| **Text** | `#F4F1E8` | Основной текст, кремовый |
| **Text secondary** | `#A8A29E` | Вторичный текст, метаданные |
| **Accent** | `#E8AE8C` | Терракота — единый акцент всей серии |

### Светлая тема
| Роль | HEX | Где |
|---|---|---|
| **Ground** | `#FAF8F5` | Фон окна (тёплый белый) |
| **Surface** | `#FFFFFF` | Карточки, elevated surface |
| **Text** | `#15181C` | Основной текст (тёмный) |
| **Text secondary** | `#78716C` | Вторичный текст |
| **Accent** | `#E8AE8C` | Терракота (тот же) |

### Glass (только светлая тема)
- Материал: `NSVisualEffectView` `.underWindowBackground`
- Density: `0.78`
- Sheen: короткий градиент сверху (не full-height wash)
- Rim: 1px `#E8AE8C` opacity 0.15 — лёгкая кромка стекла

### Правила
1. **Никакого чистого `#000` или `#FFF`** — только тёплые оттенки из палитры
2. **Accent — только для действий и состояний** (кнопки, hover, active, progress)
3. **Никаких вторых акцентов** — если нужно выделить, используй `Text secondary`

## 3. Типографика

Системный шрифт **SF Pro** (или **SF Pro Text** / **SF Pro Display**).

| Роль | Размер | Weight | Tracking |
|---|---|---|---|
| **Title (H1)** | 17 pt | Semibold (600) | 0 |
| **Body** | 13 pt | Regular (400) | 0 |
| **Caption** | 11 pt | Regular (400) | 0.02 |
| **Label** | 12 pt | Medium (500) | 0.01 |

### Правила
1. **Никаких капслоков** — только Sentence case
2. **Никаких серифов** — система должна быть незаметной
3. **Максимум 2 размера в одном экране** (Title + Body/Caption)

## 4. Пространство и отступы

Единая сетка **4pt**:

| Токен | Значение | Где |
|---|---|---|
| `space-xxs` | 2 pt | Разделители, тонкие отступы |
| `space-xs` | 4 pt | Между иконкой и текстом |
| `space-sm` | 8 pt | Внутри карточки |
| `space-md` | 12 pt | Между карточками |
| `space-lg` | 16 pt | Отступ от края окна |
| `space-xl` | 24 pt | Между секциями |

### Радиусы скругления
| Токен | Значение |
|---|---|
| `radius-sm` | 4 pt (иконки, мелкие элементы) |
| `radius-md` | 8 pt (кнопки, поля) |
| `radius-lg` | 12 pt (карточки, модалки) |

## 5. Микроанимации

Принцип: **движение должно быть незаметным**. Плавность > скорость.

### Пружины
| Токен | Параметры | Где |
|---|---|---|
| `Motion.glide` | damping 0.85, stiffness 0.18 | Панели, боковое меню |
| `Motion.settle` | damping 0.75, stiffness 0.22 | Карточки, hover |
| `Motion.quick` | damping 0.9, stiffness 0.3 | Кнопки, toggle |

### Правила
1. **Длительность: 0.2–0.35 с** (никаких 0.5+)
2. **Easing: только ease-out** (никаких bounce, elastic)
3. **Reduce Motion** — все пружины → мгновенный переход

## 6. Иконки и графика

### Стиль
- **Линейные** (outline) 1.5pt stroke, скруглённые концы
- **Заливка** только для active/selected состояний
- **Размер сетки**: 16×16, 20×20, 24×24
- **Никаких градиев** в иконках — только плоские цвета

### Логотип серии
Геометрическая абстракция: **волна / наушники**, тёмный фон + терракота.
Простая enough для 16×16 favicon.

## 7. Идентичность по приложениям

### Dajet Player
- **Акцент**: терракота в прогрессе, hover, selected playlist
- **Особенность**: glass (светлая), matte (тёмная)
- **Анимация**: tray icon dance (4 fps, 8 шагов)

### Dajet Browser
- **Акцент**: терракота в progress bar, active tab indicator
- **Особенность**: minimal chrome, скрытый toolbar до hover
- **Анимация**: tab open/close (Motion.glide)

### Kiwi Cat
- **Акцент**: терракота в UI, зелёный (#84A98C) — только для кота-киви
- **Особенность**: персонаж — главный визуальный элемент
- **Анимация**: мягкие, пружинные (Motion.settle)

### Watermelon Cat
- **Акцент**: терракота в UI, красный (#C45B5B) — только для кота-арбуза
- **Особенность**: персонаж — главный визуальный элемент
- **Анимация**: мягкие, пружинные (Motion.settle)

### Общее для котов
- Персонажи — единственные «яркие» элементы в интерфейсе
- UI вокруг них — минимальный, из основной палитры
- Никаких декоративных паттернов, скруглений «для милоты»

---

## 8. Приватность (общий принцип)

Все приложения серии:
- **Ноль сетевых запросов** в рантайме (кроме явно запрошенных пользователем)
- **Никаких аккаунтов**, облака, телеметрии
- **Никаких авто-обновлений** без запроса
- Всё хранится локально, в `~/Library/Application Support/<App>/`

## 10. Что не в планах (для всей серии)

- Аккаунты, синхронизация, облако
- Телеметрия, аналитика, трекеры
- Сторонние зависимости (только фреймворки Apple)
- Онлайн-контент без явного запроса пользователя
- Реклама, подписки, «премиум-функции»

---

## Как использовать этот документ

1. **Новые приложения** — берут палитру, типографику, отступы из этого файла
2. **Существующие** — мигрируют постепенно, начиная с акцента и текста
3. **Иконки** — рисуются по гриду 16/20/24, outline 1.5pt
4. **Анимации** — только из `Motion.*`, длительность ≤ 0.35 с

**Вопросы по бренду** — issue в [dajet-player](https://github.com/bestdeejay-design/dajet-player) с label `brand`.
